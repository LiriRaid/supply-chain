# ~/.supply-chain — private layer

Your personal memory of the supply chain. It is the same for every agent you use, it is never published, and installs and updates never overwrite it.

- `agent.md` — which skills folder and instructions file each of your agents uses.
- `profile.md` — your defaults (stacks, package managers, response language). Read when a project has no memory yet.
- `learnings/sc-<department>.md` — lessons seen once (staging), promoted to the skills when they repeat.
- `projects/<slug>.md` — one file per project: stack, architecture, verified gate commands, gotchas, decisions, repeated procedures, project skills.

Back it up or keep it in a **private** repository if you want it on several machines.
